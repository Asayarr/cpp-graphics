# 爱心曲线 —— 4 段三次 Bezier

最简单的 Bezier 综合例子：**4 段三次 Bezier 首尾相接，拼成一个爱心**。

## 数据

```cpp
static const P HEART[4][4] = {
    {{0.0,-0.76}, {-0.6,-0.30}, {-0.9, 0.10}, {-0.9, 0.40}},  // 左下 → 左边中部
    {{-0.9,0.40}, {-0.9, 0.76}, {-0.4, 0.90}, { 0.0, 0.40}},  // 左半个"心肩"
    {{0.0, 0.40}, { 0.4, 0.90}, { 0.9, 0.76}, { 0.9, 0.40}},  // 右半个"心肩"
    {{0.9,0.40},  { 0.9, 0.10}, { 0.6,-0.30}, { 0.0,-0.76}},  // 右下 → 底部尖
};
```

一共 **16 个控制点**。相邻两段共享端点，最后一段回到起点 → 闭合。

## 画面里能看到什么

| 元素 | 含义 |
|---|---|
| 红色粗线 | Bezier 曲线（曲线**不经过**中间那两个控制点） |
| 灰色折线 | 控制多边形 —— 一个"骨架"，曲线被它牵着走 |
| 灰色小圆点 | 16 个控制点 |

**这就是 Bezier 的核心直觉**：控制点像磁铁，把曲线往自己方向拉，但通常不穿过它；
同时改动任何一个控制点，会**影响整条曲线**（对比 B 样条的局部性）。

## 编译运行

```bash
cd ~/cpp-graphics/homework/爱心曲线
g++ -std=c++20 main.cpp -lglut -lGLU -lGL -o heart

```

依赖：`freeglut3-dev`、`libglu1-mesa-dev`、`libgl1-mesa-dev`
